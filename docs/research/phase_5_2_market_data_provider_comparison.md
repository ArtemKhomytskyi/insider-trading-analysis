# Phase 5.2 — historical US equity market-data provider comparison

**Source check: 2026-10-16. Research only; no market-price API calls or provider trials.** Prices, limits and terms below are public-page observations, not a quote or a license grant. `Documented` means a provider's own current documentation says it; it does **not** mean coverage for our historical security IDs was independently tested. `Unknown` means no adequate primary-source verification was found. No verified $0–$50/month option currently meets all requirements for a *full*, survivorship-bias-resistant 2006–2026 US insider-event study. The most plausible budget candidate is **EODHD Historian ($19.99/month personal plan)**: its own documentation describes full-history daily raw OHLC, split/dividend-adjusted close, separate corporate actions, and delisted-symbol retrieval. This is a **provider claim, not independently verified coverage**, and its personal-use license is expressly framed around an individual's own investment activities. The owner must ask EODHD whether this independent research project, local database storage, and any intended publication qualify. [Pricing](https://eodhd.com/pricing), [EOD specification](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes), [delisted workflow](https://eodhd.com/financial-apis/delisted-stock-companies-data-2), [terms](https://eodhd.com/financial-apis/terms-conditions).

It also forbids redistribution without a separate license. The project currently has no Tiingo key. [Pricing](https://app.tiingo.com/pricing/), [EOD fields](https://www.tiingo.com/documentation/end-of-day), [API license](https://www.tiingo.com/documentation/).

## Source-by-source assessment

### 1. Yahoo Finance through yfinance

[yfinance's own README](https://github.com/ranaroussi/yfinance/blob/main/README.md) says the package uses Yahoo's public APIs, is unaffiliated with Yahoo, and is intended for research/education while calling the underlying API personal-use only. Its [history reference](https://ranaroussi.github.io/yfinance/reference/yfinance.price_history.html) documents daily bars, actions and adjustment options. Our *offline* adapter requests raw OHLCV, `Adj Close`, splits and dividends, but neither the library nor Yahoo supplies a verified immutable historical security ID. Delisted/merged coverage, recycled ticker behavior, update policy, request quota, and bulk entitlement are **UNKNOWN**. A five-ticker response could be technically available yet historically wrong. [Yahoo's current EU-facing terms](https://legal.yahoo.com/ie/de/yahoo/terms/otos/index.html) prohibit automated collection without express prior permission; a small script is still automated. Do not begin the existing five-security run merely because code and identities are ready. Raw-series and derived-publication rights need affirmative review.

### 2. Stooq

The official [Stooq site](https://stooq.com/) was reachable only behind a browser-verification page during this review; an authoritative current price schedule, API specification, corporate-action methodology, delisted policy, and license text could **not** be verified. A third-party wrapper or CSV URL is not a license. Treat Stooq as an exploratory *manual comparison candidate* only, not an approved automated source or primary adjusted-return feed. In particular, do not infer total-return adjustments or historical security identity from a downloadable OHLCV file. No request-rate or bulk estimate is defensible from the accessible official material.

### 3. Alpha Vantage

[Documentation](https://www.alphavantage.co/documentation/) says Daily Adjusted includes raw OHLCV, adjusted close and historical split/dividend events over 25+ years, but it is premium and `outputsize=full` is premium; free `compact` is only the latest 100 observations. [Premium page](https://www.alphavantage.co/premium/) states 25 free requests/day; current numeric premium prices were not exposed in verifiable text, so price is **UNKNOWN**. `LISTING_STATUS` provides historical active/delisted lists from 2010, useful for screening, but does not prove prices for each delisted issue or cover the 2006–09 identity period. Adjusted OHLC, durable security IDs, ticker-reuse resolution and an affordable bulk feed were not documented. [Personal/commercial terms](https://www.alphavantage.co/terms_of_service/) need project/use-output review.

### 4. Financial Modeling Prep

[FMP pricing](https://site.financialmodelingprep.com/developer/docs/pricing) displays free Basic, Starter ($19/month *billed annually*, five years), Premium ($49/month *billed annually*, up to 30 years), and Ultimate ($99/month *billed annually* with bulk/batch). Monthly-billed prices and endpoint-specific entitlements are **UNKNOWN** from that display; do not treat the $49 annual-billing equivalent as an approved $49 one-month purchase. [Full historical EOD](https://site.financialmodelingprep.com/developer/docs/stable/historical-price-eod-full) offers daily OHLCV; a [separate dividend-adjusted price route](https://site.financialmodelingprep.com/developer/docs/stable/historical-price-eod-dividend-adjusted) advertises adjusted OHLC. Split fields, separate dividend/split endpoints and adjustment basis require reconciliation. FMP's own [FAQ](https://site.financialmodelingprep.com/faqs?code=platform) says delisted price history exists for *select* US companies, not all. Symbol reuse, share-class precision and a durable ID are not demonstrated. [Terms](https://site.financialmodelingprep.com/developer/docs/terms-of-service) limit personal access and require written approval for broader display/distribution; the pricing page calls for a separate data-display agreement.

### 5. Nasdaq Data Link / Sharadar SEP

[SEP documentation](https://data.nasdaq.com/databases/SEP/documentation) is the strongest specification reviewed: premium daily data from 1998, 21,000+ active/delisted tickers, raw close, split-adjusted OHLCV, a close adjusted for cash dividends/spinoffs, actions (including delist reasons and ticker changes), alternative classes and identifiers, plus a subscriber batch export. Important nuance: its `Open/High/Low/Close/Volume` are **split-adjusted**, `CloseAdj` incorporates additional events, and `CloseUnadj` is raw; these are not interchangeable return bases. Coverage and adjustment claims are vendor-documented, not independently tested for our rows. The site requires login for price, so **cost and budget fit are UNKNOWN**. [Data Link terms](https://data.nasdaq.com/terms) depend on an order form and restrict redistribution/derived use as specified there. Ask for a research quote and sample entitlements before considering it.

### 6. Tiingo

[Pricing](https://app.tiingo.com/pricing/) advertises free Starter (500 unique symbols/month, 50/hour, 1,000/day, 1GB/month) and $30 Power (larger quotas); the [EOD product](https://www.tiingo.com/products/) claims deep history for some symbols. [EOD documentation](https://www.tiingo.com/documentation/end-of-day) specifies raw and adjusted OHLCV, split factors, dividend cash, metadata start/end dates, and one date-window endpoint. This is attractive for comparing adjustment logic, but a metadata start date and ticker are not a stable point-in-time security ID; delisted/merger terminal returns and complete share-class histories remain **unproven**. [API documentation](https://www.tiingo.com/documentation/) says personal plans are internal-use only and prohibit redistribution; [terms](https://app.tiingo.com/tos/) require a commercial plan for organizational use. The owner has no token or subscription. No live work is authorized.

### 7. Massive (formerly Polygon)

[Plan prices/windows](https://massive.com/pricing?product=stocks) mean the $0–$50 target cannot reach 2006, even though the [underlying listed-US archive starts September 2003](https://massive.com/knowledge-base/article/how-much-historical-stock-data-does-massive-have). [Point-in-time ticker changes/acquisitions](https://massive.com/knowledge-base/article/how-does-polygon-handle-ticker-changes-and-acquisitions) and delisted-history claims are promising for identity QA, with important plan and issue-level caveats. [Aggregates](https://massive.com/knowledge-base/article/is-massives-stock-data-adjusted-for-splits-or-dividends) are split-adjusted by default or raw on request, **not dividend-adjusted**; use dividend/corporate-action records to construct total returns and reconcile factors. Paid bulk flat files help scale but do not lower the 20-year entitlement price. Individual plans are non-professional; [market-data terms](https://massive.com/terms/market_data_terms.pdf) must be reviewed for storage/publication. A 2006–26 full-history license is $199/month as currently displayed, beyond budget.

### 8. EODHD (additional low-cost candidate)

[Pricing](https://eodhd.com/pricing) shows $19.99/month for full-history personal EOD and 100,000 paid calls/day; free access is 20 calls/day and one year, with a limited demo-symbol set. [EOD docs](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes) specify raw OHLC, split/dividend-adjusted close, split-adjusted volume, and a separate route for split-only prices. [Delisted docs](https://eodhd.com/financial-apis/delisted-stock-companies-data-2) explicitly describe delisted ticker lists, price history, splits/dividends and US symbol-change history. [Fundamentals docs](https://eodhd.com/financial-apis/stock-etfs-fundamental-data-feeds) list CIK, ISIN, OpenFIGI, CUSIP and delisted status where populated, but do **not** establish a stable time-valid price-series identifier for every share class. Assess both coverage and terminal returns on a purposive delisted sample; a vendor statement does not remove survivorship bias. [Personal terms](https://eodhd.com/financial-apis/terms-conditions) allow private storage/manipulation/analysis but prohibit redistribution; their definition of personal use focuses on the individual's own investment activities. An independent academic-style research project with possible publication may require written clarification or a commercial license. Derived *results* are not clearly granted by the quoted language—ask specifically.

## Identity, delisting and research validity

The SEC's [CIK is a permanent filer identifier](https://www.sec.gov/submit-filings/filer-support-resources/how-do-i-guides/understand-utilize-edgar-cik-cik-confirmation-code-ccc), **not** a share-class or price-series identifier. The SEC [ticker/CIK association files explicitly lack guaranteed scope/accuracy](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data); they cannot replace dated filings and exchange notices. [Nasdaq Daily List](https://classic.nasdaqtrader.com/Trader.aspx?id=DailyListPD) describes listings, delistings and symbol changes back to 1999; [NYSE corporate-action notices](https://www.nyse.com/data-products/catalog/corporate-actions-for-nyse-group-listings) cover listing events; [OpenFIGI](https://www.openfigi.com/api/documentation) exposes instrument/share-class FIGIs. These can **validate identity**, not furnish a licensed 2006–26 adjusted daily-price panel. Historical availability, access terms and coverage must be checked for each resource.

Use dated issuer/SEC/exchange evidence to bind `(issuer CIK, security class, ticker, exchange, valid interval)` to a vendor instrument. Quarantine unknown/recycled tickers and pre-IPO/pre-change intervals; never backfill a current symbol. Keep raw, split-adjusted and dividend-adjusted series separate, reconcile splits and cash dividends, and explicitly record delisting/merger cash or stock consideration where known. A missing final price is missing—not zero and not a dropped observation. Check the first and last trading dates, long internal gaps, action discontinuities, share classes, vendor corrections and a purposive set of bankrupt/acquired names. For event studies, entry follows the **public filing acceptance**, not the insider transaction date, avoiding look-ahead. The local [five-security preflight](../../data/exports/market_data/yahoo_pilot_5_preflight.md) and [Phase 5.1 QA findings](../../data/exports/security_mapping/phase_5_1_identity_qa_findings.md) already show why ticker strings alone fail.

A continuously listed subset can support a *conditional* finding about that selected population if eligibility is defined ex ante, event timing is correct and missingness is reported. It cannot support a claim about all historical US issuers or insider trades: excluding failures, takeovers and ticker problems creates survivorship and selection bias. A small, high-quality delisted-inclusive subset is scientifically preferable to a larger silent-gap sample. Two providers can be used to **cross-check discrepancies**; they must not be spliced into one return series without compatible identities and adjustment bases.

## Cost and request scenarios

One whole-history price call per eligible, unique **vendor instrument** is a *lower bound*, not a forecast: actions/reference may add calls; endpoint row caps, pagination and date windows may split requests; retries add more. A request may yield ~5,000 daily rows for a continuously listed 20-year issue, but delisted/new issues have fewer and actual counts are **UNKNOWN**. In the current read-only mapping table there are **29,632 historical mapping rows and 21,976 distinct symbol strings**; neither number equals verified vendor instruments. The stated **622,580 accepted mapped transactions** are events, *not* 622,580 price downloads.

At 25 free Alpha Vantage requests/day, 200 *single-call* securities would require at least eight days, **but its free endpoint cannot retrieve full 2006–26 history**, so this arithmetic does not make that plan viable. At Tiingo's 50 free requests/hour, 200 history calls take at least four hours if every call counts once, excluding metadata/actions and pacing; its 500 unique-symbol monthly cap would not cover 21,976 strings in one month. These are capacity illustrations, not promises of endpoint entitlement. [Alpha limits/entitlements](https://www.alphavantage.co/premium/), [Tiingo limits](https://app.tiingo.com/pricing/).

## GO/NO-GO for Phase 5.3 forward returns

**NO-GO now.** Start return implementation only after (1) documented automated-use/storage/derived-output rights; (2) a chosen provider plan whose 2006–26 entitlement and costs fit the approved scope; (3) independently verified point-in-time issuer/security/share-class identity for included events; (4) delisted/acquired/renamed sample tested with no silent price or terminal-return gaps; (5) reconciled split/dividend treatment on one consistent return basis; (6) the 81 known suspect Phase 5.1 mappings and any overlapping identities explicitly quarantined from joins; and (7) event-time rules based on public acceptance timestamps plus missing-data denominators and a pre-declared restricted-universe interpretation. Passing a five-ticker API smoke test alone meets none of the full-universe criteria.
